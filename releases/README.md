## Installing on Android

1. Copy the APK to the phone (USB, Drive, WhatsApp, email).
2. Open it. Android will ask you to allow installs from that app: tap **Settings → Allow from this source**, go back, tap **Install**.
3. If an older version is installed it updates in place.
4. Open **Smart Poultry Farm** once and allow notifications so the "Farm Alerts" channel is created.

On GitHub, attach these files to a **Release** rather than committing new APKs into the repository.
